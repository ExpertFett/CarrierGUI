In-game GUI for AI carrier ops. Toggles with Ctrl+Shift+c and draws
inside DCS so it works in VR.

----------------------------------------------------------------
 WHAT'S IN HERE
----------------------------------------------------------------

  CARRIER tab
    LIGHTS               Off / Auto / Nav / Launch / Recovery
    TACAN / ICLS / LINK4 / ACLS    On / Off
    TURN INTO WIND       Stop / 30m / 60m / 90m / 2h / 4h / 8h
                         (auto heading + speed for CVN or LHA)

  MARSHALL tab
    RECOVERY CASE        Broadcast CASE I / II / III to all players
    MARSHAL STACK        Computes & broadcasts the USN-standard
                         CASE III stack from live carrier heading
    CHARLIE / PUSH       Broadcasts expected push time

  LSO tab
    PLAT NVG GAIN        10-segment LED bar (scroll wheel or click)
                         drives a PLAT-cam night-vision shader
    RESET CAM            One-click revert to vanilla DCS PLAT cam
                         (NVG → 0%, zoom → DEFAULT, no override)
                         — use this when daylight PLAT washes out
    WIRE TARGET          1 / 2 / 3 / 4 buttons → setDesiredRope
    DECK STATUS          Foul / Clear toggle (drives setFoulDeck +
                         broadcasts the announcement)
    PLAT ZOOM            DEFAULT / MED / TIGHT / TELE → adjustGate
                         (DEFAULT = leave DCS's dynamic zoom alone)
    LSO CALLS            WAVE OFF / CUT / BINGO / RECOVERY OK
                         (broadcasts only)
    SHIP STATUS          Live carrier HDG + wind across deck
    RECOVERY EVENTS      Auto-prompts during a CASE III approach:
                         10nm PLATFORM, 6nm comm/ICLS, 3nm tipover,
                         0.75nm "ball" — LSO sees them in the panel
                         (not broadcast)

 INSTALL — PILOTS  (EASIEST: use the .exe installer)
----------------------------------------------------------------

  1. Close DCS World if it's running.
  2. Run  CarrierGUI-Setup-v1.3-beta9.exe
  3. Wizard walks you through it. Keep defaults unless you know
     better. Next → Next → Install → Finish.
  4. Last wizard page has a checkbox:
        [x]  Apply LSO tools patch right now (recommended).
     Leave it checked unless you specifically want broadcast-only
     (no PLAT NVG amplification, no foul-deck / wire / zoom).
     That step will UAC-prompt — it needs admin to write into
     DCS's Program Files folder.
     NOTE: the LSO Tools patch modifies a core DCS shader →
     fails multiplayer integrity check. Single-player /
     IC-disabled servers only.
  5. Launch DCS, start any Supercarrier mission, Ctrl+Shift+c.

The installer drops the patcher + LSO scripts under
%LOCALAPPDATA%\Programs\CarrierGUI by default, and the hook +
.dlg under your DCS Saved Games\Scripts\Hooks. Uninstall any
time via Apps & Features → CarrierGUI.

ALTERNATIVE — zip distribution (for users who'd rather extract
manually):
  - Extract CarrierGUI-v1.3-beta9.zip somewhere.
  - Run Install.bat inside the extracted folder.
  - Same end result as the .exe installer.

----------------------------------------------------------------
 PATCH MISSIONS — MISSION DESIGNER (one per squadron, usually)
----------------------------------------------------------------

For the GUI buttons to actually do anything in a given mission,
the .miz must contain the CarrierGUI bridge. Pilots don't patch —
only whoever distributes the squadron's missions.

  1. Drag one (or many) .miz files onto:
       Patcher\Patch Mission.bat
  2. Hand out the patched .miz. (A .miz.bak backup is created on
     the first patch.)

Safe to re-run on already-patched .miz files (idempotent). Each
re-patch refreshes the embedded bridge — so when CarrierGUI gets
a new release, re-patch your missions to pick up the new bridge.

To undo: drag the .miz onto Patcher\Revert Mission.bat.

 WHAT'S NEW vs v1.2-beta5
----------------------------------------------------------------

  v1.3-beta9 is a SKELETON BETA. It widens the panel from 380→540
  px, adds two new tabs (MARSHALL and DECKBOSS), and renames the
  old MARSHALL tab to TOWER. The new tabs are empty placeholders
  in this beta — full content lands in subsequent betas:

    beta2  → TOWER stack roster (STACK / CHARLIE'D / COMMENCING)
    beta3  → MARSHALL CCZ radar (60nm) + radio readout
    beta4  → LSO overhead CASE I pattern radar
             (drops the WIRE / DECK / ZOOM / BINGO / RECOV-OK buttons)
    beta5  → DECKBOSS top-down deck view + conga overlay
    v1.3   → polish + release

  Everything from v1.2-beta5 still works in beta1: CARRIER tab is
  unchanged, the TOWER tab has the same buttons as the old MARSHALL
  tab (CASE I/II/III broadcasts, stack/Charlie broadcasts), and
  the LSO tab still has the NVG bar + Wire/Deck/Zoom/Lights. The
  Wire/Deck/Zoom buttons get retired in beta4 since they don't do
  what we hoped in-game.

 UNINSTALL
----------------------------------------------------------------

  Uninstall.bat                Removes hook + .dlg from DCS
  LSO\Disable-LsoTools.ps1     Reverts gui.fx + PLATCameraUI patches

Both leave .platcamnvg.bak files in place so you can re-enable.

----------------------------------------------------------------
 KNOWN LIMITATIONS
----------------------------------------------------------------

  - Single-player or IC-disabled servers only (modifies a core
    shader; trips the MP integrity check).
  - CASE I (visual overhead) recovery monitor: not implemented.
    Distance milestones don't map cleanly to a pattern-based
    recovery. CASE III only for the auto-prompts; everything else
    works the same regardless of case.
  - The "Bridge: probing..." status line at the bottom of the LSO
    tab may say "NOT PATCHED" even on a properly-patched mission
    if you open the panel within ~5s of mission load. Harmless.
  - DCS dxgui has no image / rotated-needle support in custom
    hooks — that's why the dial looks like an LED bar instead of
    a knob. Text widgets are all we get.

----------------------------------------------------------------
 TROUBLESHOOTING
----------------------------------------------------------------

Hotkey doesn't open the panel:
  - Restart DCS after Install.bat
  - Confirm carrier-gui-hook.lua + carrier-gui.dlg landed in
    %USERPROFILE%\Saved Games\DCS\Scripts\Hooks\
  - Check dcs.log for "CarrierGUI"

Panel opens but buttons don't do anything in-mission:
  - Drag the .miz onto Patcher\Patch Mission.bat

NVG bar / WIRE / DECK / ZOOM controls have no effect:
  - Run LSO\Enable-LsoTools.ps1 (Install.bat asks if you skipped)
  - Close DCS first — the script can't write while DCS is running

First DCS launch after LSO\Enable-LsoTools.ps1 is very slow:
  - That's expected. The shader cache is rebuilding. ~1-3 min.
