CarrierGUI — install
====================

Pilots / controllers (Open Mod Manager):
  1. Get CarrierGUI_vX.Y.ozp from the GitHub Releases page.
  2. OMM target = Saved Games\DCS  ->  install.
  3. (Recommended) (ROOT)_CarrierGUI_Images_vX.Y.ozp, OMM target = DCS install folder.
  4. In a mission: Ctrl+Shift+C.

Manual: open the .ozp as a zip, copy Scripts\ into Saved Games\DCS\.

Everything else (modes, tabs, resize, add-ons): see README.md.
